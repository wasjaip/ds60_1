# Учебные проекты по Data Science

Архив учебных проектов, выполненных в рамках программы Яндекс Практикума по Data Science.

Репозиторий сохранён как история обучения и примеры работы с классическими задачами анализа данных и машинного обучения. Для актуального портфолио см. профиль: [github.com/wasjaip](https://github.com/wasjaip).

## Темы

- предобработка и исследовательский анализ данных;
- статистический анализ и проверка гипотез;
- классификация и регрессия;
- временные ряды;
- NLP и BERT;
- компьютерное зрение;
- SQL и работа с данными.
